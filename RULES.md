# WEBCRAFT — Rulebook

## 1. Event Overview

WebCraft is a hands-on web development session by ISDC focused on layout, visual hierarchy, user experience, responsiveness, interactions, website structure, and design decisions.

The session includes a **Web Revamp Challenge** where participants analyse a curated website challenge and build an improved version from scratch.

## 2. Eligibility & Team Formation

- Participants will work in teams for the Web Revamp Challenge.
- Maximum team size: **4 participants**.
- Each participant can be part of **only one team**.
- All participants will receive an **e-certificate**.
- Winning teams will receive certificates and exciting goodies.

## 3. Web Revamp Challenge

### Challenge

Participants will receive a curated website challenge based on the concepts covered during the WebCraft session.

The team must:

1. Analyse the website.
2. Identify what can be improved.
3. Build a better version from scratch.

### Time Limit

- **1 hour** to complete the challenge.

### Technology Stack

Teams may choose any suitable technology stack, including:

- HTML
- CSS
- JavaScript
- React
- Next.js
- Any other web technology they are comfortable with

### AI Tools

AI tools **are allowed** and may be used to support development.

However, participants should:

- Understand the code they use.
- Understand how their solution works.
- Understand the decisions behind their implementation.

## 4. Challenge Flow

### 01 — Analyse

Explore the website and identify what is not working.

### 02 — Plan

Decide what needs to change and how the user experience should be improved.

### 03 — Build

Develop the website from scratch within the **1-hour challenge**.

### 04 — Present

Show the website and explain the design and technical decisions.

### 05 — Evaluate

Evaluators assess the work using the official judging criteria.

## 5. Presentation

Each team gets **5 minutes** to present.

### Presentation Structure

- **2 minutes:** Present the revamped website and explain the approach.
- **3 minutes:** Answer questions from the evaluators.

The challenge is not only about finishing a website. Teams are expected to demonstrate how they **analyse, build, explain, and defend** their choices.

## 6. Submission Guidelines

Each team must:

- Submit the GitHub repository through the submission Drive link provided by the organisers.
- Ensure the repository contains the **complete project code**.
- Use the **registered Team Name** while submitting.
- Clearly mention the assigned **Slot Number**.
- Make sure the GitHub repository is accessible to evaluators.
- Submit within the announced deadline.

## 7. Judging Criteria

**Total: 50 Marks**

### 1. Communication & Presentation — 10 Marks

Evaluators consider:

- Clarity of presentation.
- Explanation of design rationale.
- Visual presentation.
- Team coordination.

### 2. Technical Knowledge — 10 Marks

Evaluators consider understanding of:

- Web fundamentals.
- Semantics.
- UI/UX principles.
- Layout structure.
- Responsiveness.
- Performance concepts.

### 3. Approach & Problem Solving — 10 Marks

Evaluators consider:

- How effectively the team analyses the broken website.
- Identification of user friction points.
- Use of a structured problem-solving approach.

### 4. Implementation — 10 Marks

Evaluators consider:

- Quality of implementation.
- Visual execution.
- Feature completion.
- Code cleanliness.
- Responsiveness across devices.

### 5. Question & Understanding — 10 Marks

Evaluators consider the team's ability to:

- Answer evaluator questions.
- Explain technical decisions.
- Explain design decisions.
- Defend implementation choices.
- Demonstrate understanding of the solution.

## 8. Recognition

Every participant will receive an **e-certificate** for participating in WebCraft.

Winning teams will receive:

- Winner certificates.
- Exciting prizes.
- Recognition as **Web Revamp winners**.
