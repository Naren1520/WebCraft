# WebCraft 2026

🌐 **Live Broken Website:** [https://webcraft-2026.netlify.app/](https://webcraft-2026.netlify.app/)


## What's Included

- Hero section with event details and registration CTA
- About section with workshop highlights
- Speaker profiles
- Full day schedule / timeline
- Registration form
- Testimonials / success stories
- FAQ section
- Footer with contact info and newsletter signup

## Tech Stack

- Plain HTML + CSS (no frameworks or dependencies)
- Google Fonts (Inter)

## Usage

Just open `index.html` in a browser — no build step needed.

```
open index.html
```
